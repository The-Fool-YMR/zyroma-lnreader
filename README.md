# Zyroma for LNReader

1. In LNReader, open **Repositories** and add the [repository manifest](https://raw.githubusercontent.com/The-Fool-YMR/zyroma-lnreader/main/.dist/plugins.min.json).
2. Refresh the **Plugins** list and install **Zyroma**.
3. Open **Zyroma** under **Sources** and search for the novel you want to read.

Zyroma may challenge or block requests from LNReader. If the app offers **Open in WebView**, try opening Zyroma there and then retry. Live reading on Android has yet to be verified.
